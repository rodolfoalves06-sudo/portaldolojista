# Portal do Lojista Multimarcas

## 🚀 Como publicar na Vercel

### Passo 1 — Criar banco de dados
1. Acesse seu projeto no Supabase: https://xexoofzbamlgojrledek.supabase.co
2. Vá em **SQL Editor**
3. Cole o conteúdo do arquivo `CRIAR_TABELAS_SUPABASE.sql`
4. Clique em **Run**

### Passo 2 — Subir código para o GitHub
1. Acesse [github.com](https://github.com)
2. Clique em **New Repository**
3. Nome: `portaldolojista`
4. Clique em **Create repository**
5. Faça upload de todos os arquivos desta pasta

### Passo 3 — Deploy na Vercel
1. Acesse [vercel.com](https://vercel.com)
2. Clique em **Add New Project**
3. Selecione o repositório `portaldolojista`
4. Clique em **Deploy**
5. Aguarde ~2 minutos

### Passo 4 — Conectar domínio
1. Na Vercel vá em **Settings → Domains**
2. Adicione `portaldolojistamultimarcas.com.br`
3. No Registro.br configure o DNS apontando para a Vercel
